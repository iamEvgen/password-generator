# Passgen

Генератор паролей на React и TypeScript. Адаптивный интерфейс, светлая и тёмная темы, автоматическое сохранение настроек и история последних 25 уникальных скопированных паролей.

## Запуск

```sh
npm ci
npm start
```

## Проверка и сборка

```sh
npx tsc --noEmit
npx eslint src --ext .ts,.tsx --max-warnings 0
npm run build
```

Готовая сборка находится в `build/`. Путь размещения `/password-generator/` задан полем `homepage` в `package.json`.

## Поведение

- Одновременно генерируются пять паролей. Длина — от 5 до 20 символов, в пределах размера выбранного набора.
- Исходный алгоритм сохранён: перемешивание через `Math.random`, выбор символов без повторений и проверка присутствия каждой включённой категории. Повторные попытки выполняются циклом вместо рекурсии.
- При включённом исключении похожих символов не используются `l`, `I`, `O`, `1` и `0`.
- Настройки сохраняются автоматически в ключ `settings` localStorage; старый формат с полем `lenght` поддерживается.
- При первом открытии тема соответствует системной. Явный выбор сохраняется в ключ `passgen-theme`.
- Успешно скопированные из выдачи пароли сохраняются в ключ `passgen-history`, от новых к старым. Повторное копирование из выдачи переносит пароль в начало без дубликатов. Копирование из истории не меняет порядок записей и их время. Хранятся максимум 25 записей; историю можно очистить.
- История хранится в браузере в открытом виде. Приложение не отправляет пароли на сервер.
- Если localStorage недоступен, приложение продолжает работать в памяти вкладки и сообщает об ограничении сохранения.
- Нажатие на любую часть карточки пароля, в том числе в истории, копирует пароль. С клавиатуры доступны Enter и пробел. Копирование использует Clipboard API с резервным способом. При отказе обоих способов пароль можно выделить и скопировать вручную.

Дополнительные сервисы и ключи доступа для работы не нужны.
